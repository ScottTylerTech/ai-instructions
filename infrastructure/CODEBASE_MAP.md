# Budget Codebase Map

All repos across ~/git-repositories/{ai,csd,tcp,opa,petreg,terraform}. Format: **What** / **Stack** / **Depends on** / **Used by**.

## Environments & Deployment
Budget runs in three environments: **eccci** (CI), **eccqa** (QA), **eccprod** (production), each multi-region (us-west-2, us-east-1). Deployment via Argo. Config via Consul (synced from git via git2consul). Infrastructure via Terraform Cloud workspaces.

## Frontend / (~/enlistments/budget/)

**budget-chart-manager** Frontend for the user to use to manage the chart of accounts including things like accounts, account structure sets, account structures, etc. Stack: Angular, TypeScript, RxJS, some ngrx; BFF: C#, .NET 10. Depends on: budget-coa-svc, budget-api, budget-cip-svc, budget-document-svc

**budget-cip-app** Frontend for capital projects and capital plans. Capital projects are what cities use to do long term planning for their budgeting. They create capital projects to track the projects that they're budgeting for. Those become capital plans which represent the plan for a specific period of time and contains capital proposals representing each capital project. Stack: Angular, TypeScript, RxJS, ngrx; BFF: C#, .NET 10. Depends on: budget-coa-svc, budget-api, budget-cip-svc, budget-document-svc

**budget-config** Frontend for budget-wide configuration that spans the operating budget workflow. Manages departments, budget stages and stage security, proposal security, strategic goals, priorities, reporting integration settings, and AWS/S3 document imports/exports. Stack: Angular, TypeScript, RxJS, NgRx; BFF: C#, .NET 10. Depends on: budget-config-api, budget-api, budget-file-import-api, budget-business-api, budget-business-configuration-svc, budget-insights-integration, budget-cip-svc, budget-document-svc.

**budget-data-manager** Frontend and BFF for budget data operations, including dataset/file import workflows, process logs, and plan data management. Stack: Angular, TypeScript, RxJS, SCSS; BFF: C#, ASP.NET Core 8/.NET 10. Depends on: budget-api, budget-file-import-api, budget-business-api, budget-business-configuration-svc, budget-config-api, budget-coa-svc, budget-position-orchestrator-svc, budget-document-svc. Used by: budget operations/data teams, apps that rely on imported dataset and proposal line data.

**budget-integration-config-app** Frontend and BFF for external integration setup, including interactive reporting configs, budget plan export configs, capital export webhooks, import configuration, legacy hub settings, and content manager setup. Stack: Angular, TypeScript, RxJS, SCSS; BFF: C#, ASP.NET Core 8/.NET 10. Depends on: budget-integration-config-svc. Used by: org/workspace admins configuring integrations consumed by budget-plans and other export/import workflows.

**budget-plans** Frontend and BFF for operating budget planning: plan/proposal authoring, stage workflow actions, adjustments, and export orchestration. Adjustments is a known bad-neighborhood and should not be looked at for "good" code examples. Stack: Angular, TypeScript, RxJS, NgRx, SCSS; BFF: C#, ASP.NET Core 8/.NET 10. Depends on: budget-api (v1/v3/v4 clients), budget-coa-svc, budget-operating-orchestrator-svc, budget-export-orchestrator-svc, budget-integration-config-svc, budget-config-api, budget-position-orchestrator-svc, budget-business-configuration-svc. Used by: budget-config, budget-chart-manager, and core budgeting users performing plan/proposal workflows and exports.

**budget-scorecard-app** Frontend and BFF for investment/capital scorecard management, centered on scoring criteria and scorecard access in the budget suite. Stack: Angular, TypeScript, RxJS, NgRx, SCSS; BFF: C#, ASP.NET Core 8/.NET 10. Depends on: budget-scorecard-svc, budget-config-api, budget-cip-svc SDK. Used by: budget-cip-app and scorecard users evaluating/weighting capital priorities.

**budget-user-management** Frontend and BFF for user and role administration in Budget, including permission and app access management. Stack: Angular, TypeScript, RxJS, NgRx, SCSS; BFF: C#, ASP.NET Core 8/.NET 10. Depends on: budget-config-api (v1/v2 role and user clients), budget-integration-config-svc (content manager). Used by: organization/workspace administrators and any Budget app relying on centralized role/user/permission setup.

**budget-organization-config-app** Frontend and BFF for organization-level Budget product module configuration (enablement and module-level settings at org scope). Stack: Angular, TypeScript, RxJS, SCSS; BFF: C#, ASP.NET Core 8/.NET 10. Depends on: budget-config-api (ProductModule client), Tyler.PlatformApi.Data.SDK. Used by: organization administrators and provisioning/licensing flows that determine which Budget modules are active.

**budget-dashboard-app** Frontend and BFF for the Budget dashboard/landing experience, including product navigation, notifications, dashboard configuration, and integration-driven dashboard content. Stack: Angular, TypeScript, RxJS, NgRx, SCSS; BFF: C#, ASP.NET Core 8/.NET 10. Depends on: budget-config-api, budget-integration-config-svc, budget-common, tipe-core. Used by: Budget end users accessing dashboard and launch/navigation flows across Budget apps.

**budget-api** Core operating budget domain API for plans, proposals, line amounts, stage workflows, imports, process logs, and exports (v1-v4 endpoints). Contains some domain breaks that should eventually be split out such as imports, process logs, and exports. Stack: C#, ASP.NET Core 8/.NET 10, EF Core, NSwag. Used by: budget-config, budget-plans, budget-data-manager, budget-chart-manager, budget-cip-app, budget-file-import-api, budget-business-api, budget-financial-integration, budget-hub-integration, budget-position-orchestrator-svc, budget-operating-orchestrator-svc, budget-export-orchestrator-svc, budget-reporting-orchestrator-svc, budget-migrations-orchestrator-svc, budget-coa-orchestrator-svc, budget-insights-integration, budget-tenant-management-svc.

**budget-business-configuration-svc** Backend service for shared budget configuration entities (periods, departments, priorities, strategic goals, stages) used across operating and capital workflows. Represents the repository responsible for holding data specific to configuring budget business functionality. Stack: C#, ASP.NET Core 8/.NET 10, EF Core, NSwag. Depends on: budget-common-plan-access, budget-common-sanitation, Tyler.Platform.SDK, Tyler Consul configuration, TipeCore tenancy/api, AWS setup packages. Used by: budget-config, budget-plans, budget-data-manager, budget-cip-app, plus budget-business-api, budget-financial-integration, budget-hub-integration, budget-position-orchestrator-svc, budget-reporting-orchestrator-svc, budget-export-orchestrator-svc, budget-migrations-orchestrator-svc, budget-insights-integration, and budget-tenant-management-svc.

**budget-cip-svc** Capital Improvement Planning API for projects, capital plans/proposals, map features, imports, and reference data used by CIP-facing apps and downstream exports/reporting. Stack: C#, ASP.NET Core 8/.NET 10, EF Core, PostgreSQL + NetTopologySuite, NSwag. Depends on: PostgreSQL, Tyler.Platform.SDK, Tyler Consul configuration, budget-common-sanitation/source-document, TipeCore tenancy/api, AWS tenant-management packages. Used by: budget-cip-app, budget-scorecard-app, budget-chart-manager, budget-config, plus budget-hub-integration, budget-financial-integration, budget-insights-integration, budget-reporting-orchestrator-svc, budget-export-orchestrator-svc, budget-migrations-orchestrator-svc, and budget-tenant-management-svc.

**budget-coa-svc** Chart of Accounts API for accounts, segments, account structures/sets, chart parameters, and batch account operations. Stack: C#, ASP.NET Core 8/.NET 10, EF Core, NSwag. Depends on: budget-common-chart-of-accounts, budget-common-sanitation, Tyler.Platform.SDK, Tyler Consul configuration, TipeCore tenancy/api, AWS tenant-management packages. Used by: budget-chart-manager, budget-cip-app, budget-plans, budget-data-manager, plus budget-business-api, budget-financial-integration, budget-hub-integration, budget-reporting-orchestrator-svc, budget-position-orchestrator-svc, budget-export-orchestrator-svc, budget-migrations-orchestrator-svc, budget-coa-orchestrator-svc, budget-insights-integration, and budget-tenant-management-svc.

**budget-config-api** Central configuration and access-control API for roles/users, stage permissions, notifications, product modules, tenant/workspace routing helpers, and reporting integration settings. Stack: C#, ASP.NET Core 8/.NET 10, EF Core, NSwag. Depends on: PostgreSQL (configured), budget-common-permissions, budget-common-reporting, budget-common-source-document, budget-common-sanitation, Tyler Consul configuration, Tyler.Platform.SDK, TipeCore api/navigation/tenancy packages. Used by: budget-config, budget-data-manager, budget-plans, budget-scorecard-app, budget-user-management, budget-organization-config-app, budget-dashboard-app, budget-tenant-management-svc, plus budget-operating-orchestrator-svc, budget-export-orchestrator-svc, budget-reporting-orchestrator-svc, budget-migrations-orchestrator-svc, budget-common, and multiple budget-common libraries.

**budget-integration-config-svc** Backend for external integration configuration: budget plan export config, capital export webhooks, import configuration, interactive reporting config, legacy hub settings, and tenant-level integration config. Stack: C#, ASP.NET Core 8/.NET 10, EF Core, NSwag. Depends on: AWS SDK (Core, SecurityToken), Tyler.ErpArchitecture.OAuthClientAllowlisting, Tyler.Platform.SDK, Tyler Consul configuration, TipeCore configuration/tenant-management. Used by: budget-integration-config-app, budget-plans, budget-user-management, budget-dashboard-app, budget-common-content-manager/process-discovery, budget-common, budget-tenant-management-svc, budget-export-orchestrator-svc, budget-insights-integration.

**budget-scorecard-svc** Backend service for scorecard domain data (scorecards, scoring criteria, score values, criteria snapshots) used in capital prioritization workflows. Stack: C#, ASP.NET Core 8/.NET 10, EF Core, PostgreSQL, NSwag. Depends on: PostgreSQL, budget-common-sanitation/source-document, Tyler.Platform.SDK, Tyler Consul configuration, TipeCore tenancy/api, AWS tenant-management setup. ## Integrations / (~/enlistments/budget/)
**budget-export-orchestrator-svc** Orchestrates asynchronous operating/capital export flows to downstream systems, including export task lifecycle and compensating transaction handling. Stack: C#, ASP.NET Core 8/.NET 10, EF Core, AutoMapper, NSwag. Depends on: budget-api, budget-config-api, budget-file-import-api, budget-business-configuration-svc, budget-coa-svc, budget-cip-svc, budget-integration-config-svc, budget-scorecard-svc, budget-document-svc. Used by: budget-plans, budget-cip-app.

**budget-file-import-api** Backend import API for file ingestion and processing (including CSV import/export templates), with dataset processing endpoints and queued import execution. The service takes in a files and creates a C# entity object that represents that file, which can then be used by other services for import. Stack: C#, ASP.NET Core 8/.NET 10, EF Core (SQLite), CsvHelper, NSwag. Depends on: budget-api, budget-business-api. Used by: budget-chart-manager, budget-config, budget-data-manager, budget-export-orchestrator-svc.

**budget-financial-integration** External integration API for financial-system imports into Budget (accounts, segment codes, position forecasts, project numbers, and related dataset endpoints). Stack: C#, ASP.NET Core 8/.NET 10, EF Core (SQLite), AutoMapper, NSwag. Depends on: budget-api, budget-business-api, budget-coa-svc, budget-cip-svc, budget-business-configuration-svc. Used by: external ERP/financial systems.

**budget-hub-integration** OData-focused integration/query layer for budget/capital plans, proposals, notifications, and menu metadata; provides queryable projection endpoints for integration/reporting consumers. Stack: C#, ASP.NET Core 8/.NET 10, OData, EF Core (SQLite), AutoMapper, Swashbuckle. Depends on: budget-api, budget-reporting-orchestrator-svc, budget-business-configuration-svc, budget-coa-svc, budget-cip-svc. Used by: external/direct HTTP and OData consumers.

**budget-reporting-orchestrator-svc** Aggregation/orchestration service for reporting across budget proposals, capital proposals/plans, and position forecast datasets, exposing versioned reporting APIs. Stack: C#, ASP.NET Core 8/.NET 10, EF Core, AutoMapper, Npgsql NetTopologySuite, NSwag. Depends on: budget-api, budget-config-api, budget-business-configuration-svc, budget-coa-svc, budget-cip-svc, budget-scorecard-svc. Used by: budget-hub-integration, budget-insights-integration.

**budget-document-svc** Document lifecycle service for upload/download and file scan workflows with S3-backed storage and tenant-aware object management. Stack: C#, ASP.NET Core 8/.NET 10, AWS SDK (S3/SQS/DynamoDB/STS), LocalStack, NSwag. Depends on: none (budget repos). Used by: budget-chart-manager, budget-cip-app, budget-common, budget-config, budget-data-manager, budget-export-orchestrator-svc, budget-migrations-orchestrator-svc, budget-tenant-management-svc.

**budget-spatial-integration-svc** Backend service for spatial/geographic integration features used by Budget workflows, exposing versioned APIs around locator/spatial data and related chart-of-accounts-safe payload handling. Stack: C#, ASP.NET Core 8/.NET 10, NetTopologySuite, TipeCore, NSwag. Depends on: budget-common, tipe-core. Used by: external/direct HTTP consumers.

**budget-insights-integration** Backend integration service for Budget insights/Tyler Data Store style reporting sync, strategic-goal/scorecard-aware insights shaping, and related document/reporting integration flows. Stack: C#, ASP.NET Core 8/.NET 10, EF Core (SQLite), AWS SDK, TipeCore, NSwag. Depends on: budget-api, budget-reporting-orchestrator-svc, budget-cip-svc, budget-coa-svc, budget-scorecard-svc, budget-business-configuration-svc, budget-integration-config-svc, budget-common, tipe-core, budget-test-data. Used by: budget-config, budget-migrations-orchestrator-svc, budget-tenant-management-svc.

## Infrastructure (~/enlistments/budget/)
**budget-gitops** GitOps manifest synthesis repo for Budget deployments across CI, QA, and production environments. Generates per-service Kubernetes/application manifests and allowlist config from typed constructs rather than storing only handwritten YAML. Creates a connection between the infrastructure in aws (defined in budget-infrastructure) and the application environment that the application containers run in. Stack: TypeScript, Node.js, eco-gitops CLI/common, cdk8s-style construct synthesis. Depends on: none (budget repos). Used by: most deployable Budget service repos through CI/CD workflow variables pointing GITOPS_REPO at budget-gitops, plus budget-tenant-management-svc and budget-dev-env-compose through generated instance manifests.

**budget-infrastructure** Central Terraform repo for Budget AWS infrastructure and per-service environment configuration. Organizes infra by service and environment (ci/qa/prod/prod-sand) and includes shared platform resources used across the Budget estate. Stack: Terraform, Terraform Cloud, AWS provider modules/workflows. Depends on: none (budget repos). Used by: budget-tf-workspace-management and external/direct infrastructure consumers.

**budget-tenant-management-svc** Tenant/workspace lifecycle service for Budget provisioning and tenant-management operations, built on the Tyler tenant-management platform stack and exposing an SDK for orchestration/provisioning flows. Supports Snapshot operations, new tenant provisioning, etc. Stack: C#, ASP.NET Core 8/.NET 10, TipeCore tenant-management/configuration, Tyler ErpArchitecture tenant-management packages, NSwag. Depends on: budget-api, budget-config-api, budget-business-configuration-svc, budget-coa-svc, budget-document-svc, budget-cip-svc, budget-scorecard-svc, budget-integration-config-svc, budget-insights-integration. Used by: budget-gitops, budget-infrastructure, budget-dev-env-compose, budget-automation-taf, budget-tf-workspace-management.

**budget-workflow-manager** Shared GitHub Actions workflow repo for Budget CI/CD and contract-testing automation. Provides reusable workflows for code freeze checks, Pact contract tests, verification-published handling, dependency enforcement, faker-based tests, and secret rotation. Stack: GitHub Actions workflows, Pact/PactFlow-oriented CI automation. Depends on: none (budget repos). Used by: most deployable Budget service repos via reusable uses: tyler-technologies/budget-workflow-manager/... workflow references, including budget-api, budget-business-api, budget-cip-svc, budget-document-svc, budget-file-import-api, budget-operating-orchestrator-svc, and budget-position-orchestrator-svc.

**budget-terraform-shared** Shared Terraform module/configuration repo for Budget infrastructure building blocks that are reused by service-specific infrastructure stacks. Stack: Terraform. Depends on: none (budget repos). Used by: budget-tf-workspace-management and infrastructure provisioning flows that compose shared Budget Terraform modules.

**budget-tf-workspace-management** Terraform Cloud workspace-management repo that renders and manages Budget appstack/workspace configuration from YAML definitions across environments. Stack: Terraform, YAML, Gomplate templating. Depends on: budget-infrastructure. Used by: budget-tenant-management-svc and Budget infrastructure/DevOps operations managing Terraform Cloud workspace configuration.

**eco-rt53** Terraform repo for Route53/DNS delegation and domain routing across Budget and related ecosystem environments. Stack: Terraform. Depends on: none (budget repos). Used by: external/direct infrastructure consumers.
