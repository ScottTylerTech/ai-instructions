Get started

Install once. Let the agent route the rest.

Install from the GitHub source for the preferred update path. Copilot discovers relevant skills on demand and checks the source for plugin updates.

01

VS Code

  1. Open the Command Palette with Ctrl + Shift + P.
  2. Run this command.
    Chat: Install Plugin From Source
  3. Enter the repository source.
    tyler-technologies/budget-ai-instructions
VS Code plugin documentation ↗
02

Copilot CLI

  1. Add the repository as a marketplace source.
    copilot plugin marketplace add tyler-technologies/budget-ai-instructions
  2. Refresh marketplace metadata.
    copilot plugin marketplace update
  3. Update installed plugins.
    copilot plugin update --all
